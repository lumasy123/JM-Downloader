# JM下载器

输入 JM 号下载漫画，下载后放在书架上离线看。手机端界面，可「添加到主屏幕」当 App 用。

**安卓安装包**：到 [Releases](https://github.com/lumasy123/JM-Downloader/releases) 下载最新的 `.apk`，装上就能用，不需要电脑。

**Windows 电脑版**：到 [Releases](https://github.com/lumasy123/JM-Downloader/releases) 下载 `JM-Downloader-Setup-x.x.x.exe`，
双击安装（默认装到当前用户，不需要管理员权限），开始菜单 / 桌面上就有「JM下载器」，功能和安卓版一样。

- 书架：列表 / 封面墙，分组、多标准评分（按平均分排序、筛选）、每本可写笔记、记点开次数
- 下载：输入 JM 号（可多个）或关键字搜索，带实时进度；搜索结果按收藏的标签、作者排序；
  「探索」按收藏标签一次挑 15 本没下过的，可以换一批
- 动态：书架上的连载出了新章节、收藏作者一个月内的新本、和收藏标签最搭的新本（分两栏）；有新的会提醒
- 阅读：整本连续竖滑、进度条跳页、点击隐藏界面、自动记住看到第几页；阅读记录统计每天看了多少
- 空间：单本压缩画质、导出 ZIP / PDF；存储页推荐读完且很久没开的书；每周自动备份

---

## 方式一：电脑当服务器，手机看（最简单）

1. 电脑上双击 **`启动书架.bat`**，窗口里会显示两个地址。
2. 手机连**同一个 Wi-Fi**，浏览器打开窗口里那个 `http://192.168.x.x:8080`。
3. 浏览器菜单里选「添加到主屏幕」，之后点桌面图标就能直接进。

漫画存在电脑的 `downloads` 文件夹里。**看的时候电脑要开着**。

## 方式二：全装在手机上（不用开电脑）

漫画直接下到手机里，断网也能看。需要装 Termux：

1. 装 [Termux](https://f-droid.org/packages/com.termux/)（用 F-Droid 版，应用商店的版本太旧）。
2. 把这个文件夹拷到手机，例如 `内部存储/jmshelf`。
3. Termux 里依次执行：

   ```bash
   pkg install python -y
   pip install jmcomic pillow
   termux-setup-storage          # 授权访问手机存储
   cd ~/storage/shared/jmshelf
   python server.py
   ```

4. 手机浏览器打开 `http://127.0.0.1:8080`，「添加到主屏幕」。

这种方式是 `localhost`，浏览器会当成安全环境，PWA 功能完整（全屏、独立图标、界面离线缓存）。

以后每次用：打开 Termux → `cd ~/storage/shared/jmshelf && python server.py` → 点桌面图标。

## 电脑版（Windows 桌面端）

和安卓版一个思路：程序在后台跑同一份 `server.py`，前面用系统自带的 Edge 内核（WebView2）开一个独立窗口。

- **数据位置**：书、封面、收藏、评分等默认放在 `%APPDATA%\JM下载器`，设置 →「存储位置」可以打开文件夹，
  或者换到别的盘（会整个搬过去并自动重启）。卸载程序不会删这些数据。
- **和安卓版的区别**：「分享」在电脑上是「另存为」，阅读器的「横屏」按钮是全屏；其余完全一样。
- **换设备**：两边都用 我的 →「导出 / 导入」→ 完整备份（书本身需要重新下载，或者直接把数据文件夹拷过去）。

自己打包安装包：

```bash
pip install pyinstaller pywebview
winget install JRSoftware.InnoSetup
python desktop/build.py          # 输出 dist/JM下载器-安装包-<版本>.exe
```

打出来的安装包只含程序，不含任何个人数据（打包脚本会检查）。直接跑源码调试：`python desktop/app.py`。

## 配置

改 `config.json`（第一次启动会自动生成）：

| 项 | 说明 | 默认 |
|---|---|---|
| `port` | 端口 | `8080` |
| `proxy` | 代理，如 `127.0.0.1:7890`；留空用系统代理 | `""` |
| `download_dir` | 漫画存放目录 | `"downloads"` |
| `threads` | 同时下载的图片数，网差就调小 | `20` |

改完要重启服务。

## 命令行版

不想开界面时，用 `jm.py` 直接下载（会额外生成 PDF）：

```bash
python jm.py 422866
```

或双击 `jm.bat` 交互式输入。

## 改代码后重新打包

改完 `server.py` 或 `web/` 里的文件，跑一条命令就行，不用手动同步或改版本号：

```bash
python deploy.py
```

| 命令 | 做什么 |
|---|---|
| `python deploy.py` | 同步 → 构建 → 装进 MuMu 并启动（日常迭代） |
| `python deploy.py apk` | 同步 → 构建 → 生成 `JM下载器.apk`（要发布时） |
| `python deploy.py both` | 两样都做 |

装进 MuMu 后会自动把 8777 端口转发到电脑，可以直接
`curl http://127.0.0.1:8777/api/shelf` 调接口，或在电脑浏览器里打开调试。

界面资源的版本号由文件内容算出来，改了自动变，不会出现 WebView 拿旧缓存的问题。

构建工具链装在 `D:\androidbuild`（JDK 21、Android SDK 34、Gradle 8.7、
Python 3.11），安卓外壳工程（Chaquopy + WebView）在 `android/`。`server.py` 和 `web/`
由 `deploy.py` 每次同步进去，工程里不重复存。在别的电脑上构建，要改 `deploy.py` 开头的工具链路径、
`android/app/build.gradle` 里的 `buildPython`，并新建 `android/local.properties` 写上 `sdk.dir`。

### 安卓版的两个特殊处理

- `curl_cffi`：jmcomic 依赖它，但那是原生库、安卓没有轮子。工程里放了桩模块
  让 import 能过，网络层换成纯 Python 的 `requests`。
- WebP：Chaquopy 的 Pillow 没编进 WebP 支持，而禁漫图片都是 WebP。
  `android_webp.py` 借系统的 BitmapFactory 解码后再交回 PIL。

## 看板娘

底栏上站着的小人。点她说话，左右拖换位置，长按收起，收起后点底栏上的小鲸鱼叫回来；
设置 → 外观 →「看板娘」也能开关。提示、通知、首次使用教程在她能看到时都由她来说，
下载完成 / 失败时，气泡里会带「去看看」「重试」按钮。点她、或一阵子不操作她低头看漫画时，
会时不时拿书架上的标签、作者打趣。

- **话量**：设置 → 外观 →「看板娘话量」分安静 / 正常 / 话多，深夜会自动安静些。
- **改台词**：编辑 `web/pet-lines.json`，每条是 `["动作", "话"]`，文件开头写了动作名和占位符的用法。
  改完刷新页面就生效，打包进安卓跑 `python deploy.py`。
- **素材**：`pet_src/` 里是原图和生成脚本。
  `make_pet.py` 把原图拆成身体 / 小鲸鱼 / 闭眼三层；`make_poses.py` 把生图拼图抠成各个动作
  （命令写在文件开头）；`make_icons.py` 生成网页和安卓图标。

## 一键遮挡

顶栏的眼睛按钮：封面盖上纯色，标签除了中文、汉化、全彩、同人这类说明性质的全部盖住，
标题和作者名不遮。设置 → 隐私 里可以追加不想遮的标签。

## 搜索

书架和下载页都支持空格隔开多个关键字，可选「同时包含」或「包含其一」（两处共用一个设置）；
词前加 `-` 表示排除，比如 `校服 -NTR`。

## 黑名单和收藏

- 搜索结果每本下面有「拉黑」「收藏」：弹窗里挑这一本、作者、标签。拉黑的不再出现在搜索里；
  收藏的标签命中越多、有收藏作者的，搜索时排得越前（设置里可选只排当前页，或前 5 页一起排）。
- 「我的」里能管理本子 / 标签 / 作者黑名单，以及收藏的标签、作者。
- 同一部作品的其他汉化版如果书架上已经有了，搜索结果里会标「书架有同名」。

## 评分和笔记

详情页章节列表下面有「评分」按钮：弹窗里按每个评分项打 1~5 星，综合分是各项的平均，
书架上显示成星级，可以按评分排序、按「4 分以上 / 3 分以上 / 未评分」筛选。
评分项（默认画面、剧情、实用性）能在评分窗口里直接增删。笔记写在评分下面，书架搜索也能搜到。

## 导出 / 导入号单

「我的」→「导出号单」：勾选书架 JM 号、黑名单、收藏名单，选「复制文字」或「分享 / 保存文件」。
另一台设备上「导入号单」粘贴文字或选文件，预览里挑要下载的书、要导入的名单。

## 代码结构和测试

- `server.py`：内置服务，下载、书架、搜索、动态、探索、名单、评分、备份都在这里。
- `web/`：界面。`app.js` 是主体（书架、详情、阅读器、下载、设置）；`lists.js` 黑名单 / 收藏 / 评分，
  `feed.js` 探索和动态，`io.js` 号单导出导入，`pet.js` 看板娘，`mask.js` 一键遮挡。
- 服务端有一套离线测试（临时目录里跑，不联网、不碰真实数据）：

  ```bash
  python -m unittest discover tests -v
  ```

## 说明

- 下载失败多半是网络问题，配个代理再试。
- 手机连不上电脑：确认在同一个 Wi-Fi，并在 Windows 防火墙里允许 Python 走「专用网络」。
- 书架里删除会连同本地图片一起删掉。
- 仅供个人离线阅读，请遵守相关网站条款。
